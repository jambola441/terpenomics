Payload Comparison p002

Measured on a 1-page synthetic COA PDF (1,466 bytes).

MetricOld approachNew approach
Message body bytes (1-page) 197,132 bytes (b64 PNG) ~200 bytes (file_id)
Message body bytes (3-page) ~591,000 bytes (3× b64 PNGs) ~200 bytes (same file_id)
Upload payload — 1,466 bytes (the raw PDF once)
Payload reduction per page — 99%
Server-side rasterization Client-side (PyMuPDF) Anthropic-side (free)
Text layer available to Claude No — image only Yes — text + image

Why the message body is so much smaller

The old approach embedded the full base64-encoded PNG (197 KB/page) directly in the messages request body. The new approach puts the PDF on Anthropic's storage once, then passes just a 40-char file ID string in the message. Anthropic processes it server-side — the round-trip payload shrinks by 99%.
