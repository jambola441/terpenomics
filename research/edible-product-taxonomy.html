Taxonomy

Five subcategories, a 46% unclassified rate, and why brand identity beats name parsing for edibles.

The edibles shelf looks homogeneous from the outside — everything goes in the edible bucket. But gummies, chocolates, beverages, and tablets are genuinely different products that should differentiate in the identity tuple.

"Live Rosin" Is Quality, Not Type r015

Many listings embed extract quality in the name. This is not a type signal — it's an ingredient tier.

Wrong — splits the type

(Camino, "live-rosin-gummy", "Chill", "10mg")
(Camino, "gummy", "Chill", "10mg")
→ treated as different products

Right — quality is extra_info

(Camino, "gummy", "Chill", "10mg",
  extract="live-rosin")
(Camino, "gummy", "Chill", "10mg",
  extract="distillate")
→ variants of same type

Same rule applies to "Live Resin", "Hash Rosin", "Nano" — all quality/extraction markers, not format types.

Recommendation r016

Four typed edible subtypes in the enum + a brand-level lookup layer to cover unlabeled gummy brands.

class ProductCategory(str, Enum):
    # edible subtypes
    gummy     = "gummy"      # all soft candy forms
    chocolate = "chocolate"  # bars, confections
    beverage  = "beverage"   # drinks, tea, sparkling water
    tablet    = "tablet"     # pills, caps, sublingual
    # edible = "edible" ← remove
