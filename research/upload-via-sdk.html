Current Approach r010

What services/lab_report_parser.py does today

Rasterize with PyMuPDF Each page rendered to a 200 DPI PNG via fitz.open(...)
Base64-encode each PNG base64.standard_b64encode(png_bytes)
One API call per page client.messages.create with type:"base64", media_type:"image/png" — per page, in a loop
Merge results across pages _merge_extractions() picks the page with the most terpenes

N pages = N API calls. Image-only. No text layer.

Files API Approach

  • 200 DPI rasterization
  • Per-page base64 encoding
  • N separate API calls
  • Manual page merging
  • Image-only (no text layer)

After

  • No rasterization needed
  • 1 upload call (free)
  • 1 message call (all pages)
  • 1 delete call (cleanup)

  • Simpler, more accurate
03 / 09

How Native PDF Processing Works r007

Text extraction Anthropic extracts the embedded text layer from each page of the PDF
Visual rendering Anthropic renders each page as an image (like rasterization — but done server-side)
Claude sees both Claude receives text + image for every page simultaneously in a single document block

Why this matters for lab reports

Cannabis COAs are text-heavy PDFs (tables of terpene names + percentages). With the current approach Claude must OCR rasterized pixels. With native PDF, Claude reads the structured text layer directly — significantly more accurate for column values, terpene names, and lab metadata.

Three Ways to Send a PDF r009

All three use a document block and trigger the same native PDF processing.

source.typeHow it worksBest forRequest payload
"file" Reference an uploaded file by ID Lab report parser (repeated uploads, batch) Tiny — just the ID
"base64" Embed PDF bytes directly in the request One-shot, no upload step wanted Entire PDF in body
"url" Point to a publicly hosted PDF URL PDFs already on a CDN Just the URL

Recommendation for the lab report parser

Use type: "file". The PDF comes in from a user upload, so it's available as bytes. Upload → extract → delete keeps storage clean and payload tiny.

Cost Tradeoff r012

Current approach

  • Image tokens only (per page)
  • Upload/delete: N/A
  • PyMuPDF compute cost (local)
  • N API calls = N × latency

Files API approach

  • Image tokens + text tokens per page
  • ~1,500–3,000 text tokens/page additive
  • Upload / delete operations free
  • 1 API call = lower total latency
  • No PyMuPDF compute

Bottom line

Native PDF costs slightly more per page in tokens (due to text layer), but eliminates N-1 extra API round-trips, reduces latency, and improves accuracy — a net win for a document extraction workload like lab report parsing.

07 / 09

Risks r014 r011

Beta instability

The files-api-2025-04-14 header signals this is a beta API. Breaking changes are possible before GA. Rate limits may tighten.

ZDR ineligibility

Files API is NOT eligible for Zero Data Retention. Organizations with ZDR requirements cannot use this beta feature — files remain on Anthropic infrastructure until deleted.

Platform lock-in

Only works with the direct Anthropic API. If this project ever needs to move to AWS Bedrock or Google Vertex AI, the Files API upload step would need to be removed.

Mitigation

Delete files immediately after extraction. The upload-extract-delete pattern minimizes retention exposure. Watch the changelog for GA announcement.

def extract_from_pdf(pdf_bytes: bytes) -> COAExtraction:
    client = _make_client()
    import io

    # 1. Upload the PDF
    upload = client.beta.files.upload(
        file=("report.pdf", io.BytesIO(pdf_bytes), "application/pdf"),
    )

    try:
        # 2. Single message call — all pages, text + image
        response = client.beta.messages.create(
            model="claude-haiku-4-5",
            max_tokens=1024,
            betas=["files-api-2025-04-14"],
            system=[{"type": "text", "text": SYSTEM_PROMPT, "cache_control": {"type": "ephemeral"}}],
            messages=[{
                "role": "user",
                "content": [
                    {"type": "document", "source": {"type": "file", "file_id": upload.id}},
                    {"type": "text", "text": "Extract all terpene data and report metadata. Return only the JSON object as specified."},
                ],
            }],
        )
        raw_text = response.content[0].text.strip()
        raw_text = re.sub(r"^```(?:json)?\s*", "", raw_text)
        raw_text = re.sub(r"\s*```$", "", raw_text)
        data = json.loads(raw_text)
        return COAExtraction.model_validate(data)
    finally:
        # 3. Clean up — don't accumulate stored files
        client.beta.files.delete(upload.id)
