The Pattern

What "thin API / thick scripts" means here

API does
  • → Single-resource CRUD (create one product, update one listing)
  • → Validation and constraint enforcement
  • → Auth, pagination, filtering
  • → Returns a well-typed response
Scripts do
  • → Read a CSV / external API / file
  • → Decide what to create vs update
  • → Loop, batch, cache, retry
  • → Emit a human-readable summary
# Script drives the API — API stays dumb
